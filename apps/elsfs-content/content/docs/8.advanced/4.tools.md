Nuxt Content 使用 **SQLite 数据库（`contents.sqlite`）** 来高效地存储和查询内容。如果你遇到 **内容缺失、查询缓慢或数据库问题**，调试 SQLite 数据库可能会帮上忙！  

::callout
---
icon: i-simple-icons-visualstudiocode
to: https://marketplace.visualstudio.com/items?itemName=alexcvzz.vscode-sqlite
---
想找个简单的查看方式？**用 SQLite VS Code 扩展！**
::

## 安装 SQLite VS Code 扩展  

1. 打开 **Visual Studio Code**。  
2. 进入 **扩展**（Extensions）面板（`Ctrl+Shift+X` / Mac 上为 `Cmd+Shift+X`）。  
3. 搜索 **"SQLite"**（作者为 `alexcvzz`）并安装。  
4. 打开你的 Nuxt Content 数据库（`.data/content/contents.sqlite`）。  

::tip{icon="i-lucide-lightbulb"}
如果看不到 `contents.sqlite`，请先启动你的 Nuxt 应用：

```bash [Terminal]
npx nuxi dev
```
::

## 找到你的 SQLite 数据库  
Nuxt Content 把数据库存放在这里：  

```bash
.data/content/contents.sqlite
```

::note{to="https://nuxt.com/docs/getting-started/prerendering"}
这个文件会在你启动 Nuxt 应用时自动生成，无需手动创建！  
::

## 打开并浏览数据库  

1. 在 VS Code 中**右键点击** `contents.sqlite`。  
2. 选择 **"Open Database"**。  
3. 展开 **Database Explorer** 面板，即可查看数据表和其中的数据。  

![VS Code 中的 SQLite Explorer](https://github.com/user-attachments/assets/c9f22c4c-7a95-43e8-ab03-aa76f2e49c8e)

## 修复常见问题  

### 内容不显示？  

1. **检查数据库是否存在**（`.data/content/contents.sqlite`）。  
2. **执行清理并重启 Nuxt**：  
   ```bash [Terminal]
   npx nuxi cleanup && npx nuxi dev
   ```
3. **检查内容是否已在数据库中**（执行一条 SQL 查询）。  

### 手动重置数据库  
如果情况看起来**确实很糟**，可以试着重置它：  

1. **删除数据库文件**：  
   ```bash [Terminal]
   rm -rf .data/content/contents.sqlite
   ```
2. **执行清理**以移除旧缓存：  
   ```bash [Terminal]
   npx nuxi cleanup
   ```
3. **重启 Nuxt** 以生成全新的数据库：  
   ```bash [Terminal]
   npx nuxi dev
   ```

::note{icon="i-lucide-triangle-alert"}
清理会移除缓存数据。别担心，它会自动重新生成！
::

## 更多调试工具  
如果 VS Code 还不够用，可以看看：  

- 🖥️ [**DB Browser for SQLite**](https://sqlitebrowser.org/) – 用于查看和修改数据库的可视化工具。  
- 🛠️ **SQLite Command Line** – 使用 `sqlite3 contents.sqlite` 在终端中运行 SQL 查询。
