Nuxt Content 中的转换器让你可以在内容文件被处理时，以编程方式解析、修改或分析它们。它们尤其适用于以下场景：

- 添加或修改字段（例如在标题后追加内容、生成 slug）
- 提取元数据（例如列出用到的组件）
- 用计算出的数据充实内容
- 支持新的内容类型

## 定义转换器

你可以使用 `@nuxt/content` 提供的 `defineTransformer` 辅助函数来定义转换器：

```ts [~~/transformers/title-suffix.ts]
import { defineTransformer } from '@nuxt/content'

export default defineTransformer({
  name: 'title-suffix',
  extensions: ['.md'], // File extensions to apply this transformer to
  transform(file) {
    // Modify the file object as needed
    return {
      ...file,
      title: file.title + ' (suffix)',
    }
  },
})
```

### 转换器选项

- `name`（string）：转换器的唯一名称。
- `extensions`（string[]）：该转换器适用的文件扩展名（例如 `['.md']`）。
- `transform`（function）：接收文件对象并返回修改后文件的函数。

## 注册转换器

转换器在你的 `nuxt.config.ts` 中注册：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  content: {
    build: {
      transformers: [
        '~~/transformers/title-suffix',
        '~~/transformers/my-custom-transformer',
      ],
    },
  },
})
```

## 示例：添加元数据

转换器可以为文件添加一个 `__metadata` 字段。该字段不会存入数据库，但可用于运行时逻辑。

```ts [~~/transformers/component-metadata.ts]
import { defineTransformer } from '@nuxt/content'

export default defineTransformer({
  name: 'component-metadata',
  extensions: ['.md'],
  transform(file) {
    // Example: Detect if a custom component is used
    const usesMyComponent = file.body?.includes('<MyCustomComponent>')
    return {
      ...file,
      __metadata: {
        components: usesMyComponent ? ['MyCustomComponent'] : [],
      },
    }
  },
})
```

**注意：** `__metadata` 字段只在运行时可用，不会持久化到内容数据库中。

## API 参考

```ts
interface Transformer {
  name: string
  extensions: string[]
  transform: (file: ContentFile) => ContentFile
}
```

- `ContentFile` 是表示已解析内容文件的对象，包含 frontmatter、body 以及其他字段。

## 用转换器支持新的文件格式

转换器并不局限于修改已有内容，它们还可以用来为 Nuxt Content 增加对新文件格式的支持。通过定义一个带有自定义 `parse` 方法的转换器，你可以告诉 Nuxt Content 如何读取和处理新扩展名的文件，例如 YAML。

### 示例：支持 YAML 文件

假设你想在内容目录中支持 `.yml` 和 `.yaml` 文件。你可以创建一个转换器来解析 YAML 的 frontmatter 和正文，并为这些扩展名注册它：

```ts [~~/transformers/yaml.ts]
import { defineTransformer } from '@nuxt/content'

export default defineTransformer({
  name: 'Yaml',
  extensions: ['.yml', '.yaml'],
  parse: (file) => {
    const { id, body } = file
    
    // parse the body with your favorite yaml parser
    const parsed = parseYaml(body)

    return {
      ...parsed,
      id,
    }
  },
})
```

像注册其他转换器一样，在你的 Nuxt 配置中注册这个 YAML 转换器：

```ts
export default defineNuxtConfig({
  content: {
    build: {
      transformers: [
        '~~/transformers/yaml',
        // ...other transformers
      ],
    },
  },
})
```

这种方式让你可以扩展 Nuxt Content，以处理任何你需要的自定义文件格式。
