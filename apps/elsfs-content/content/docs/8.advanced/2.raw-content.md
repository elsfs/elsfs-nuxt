---
title: 原始内容
description: 在应用中访问内容的原始数据
---

在 Content 第 2 版中，很多用户提出希望在生产环境访问内容的原始数据。到了 Content 第 3 版，已经可以将内容的原始数据一起发布到生产环境。

为了把原始内容发布到生产环境，你需要在集合的模式中定义 `rawbody` 字段，仅此而已。

Nuxt Content 会检测到你模式中的这个特殊字段，并为其填充原始内容。

```ts [content.config.ts]

import { defineCollection, defineContentConfig } from '@nuxt/content'
import { z } from 'zod'

export default defineContentConfig({
  collections: {
    docs: defineCollection({
      source: '**',
      type: 'page',
      schema: z.object({
        rawbody: z.string()
      })
    })
  }
})
```

之后你可以使用 `queryCollection()` 获取原始内容。

```vue [pages/index.vue]
<script setup lang="ts">
const route = useRoute()
const { data } = useAsyncData('page-' + route.path, () => queryCollection('docs').path(route.path).first())
</script>

<template>
  <pre>{{ data.rawbody }}</pre>
</template>
```

如果你不想发布某个特定文件的原始内容，可以在该文件的 frontmatter 中添加 `rawbody: ''`。自动填充的 `rawbody` 值相当于默认值，一旦你在 frontmatter 中定义了 `rawbody`，它就会被覆盖。

```md [content.md]
---
title: My page
rawbody: ''
---

```

::callout
为 frontmatter 字段填充数据时，务必使用与集合模式中定义一致的数据类型。这里的 `rawbody` 是字符串，因此应当传入空字符串。不要使用 `boolean` 或其他类型的值。
::
