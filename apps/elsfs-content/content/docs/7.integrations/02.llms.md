Nuxt Content 模块集成了 `nuxt-llms`，用于让你的内容适配大语言模型（LLMs）。当检测到 `nuxt-llms` 时，Content 模块会自动扩展 LLMs 模块，并把 [page](https://content.nuxt.com/docs/collections/types#page-type) 类型的集合注入 LLMs 模块。🚀

如果希望在保留 `nuxt-llms` 安装的同时关闭该集成，可将 [`content.llms`](/docs/getting-started/configuration#llms) 设为 `false`。

## 配置

::prose-steps
### 安装所需模块

```bash [terminal]
npm install nuxt-llms
```

### 配置你的 `nuxt.config.ts`

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/content', 'nuxt-llms'],
  llms: {
    domain: 'https://your-site.com',
    title: 'Your Site Name',
    description: 'A brief description of your site',
  },
})
```
::

就这样 🚀 `/llms.txt` 文件会自动生成并预渲染。

## 原始 Markdown 访问

启用 `nuxt-llms` 后，Nuxt Content 还会暴露一个原始 Markdown 端点，让你无需经过完整的渲染流程，就能输出可直接供 LLM 使用的源文件。

- **端点**：`/raw/<content-path>.md`（使用与页面 URL 相同的路径，去掉末尾的 `/index`，保留 `.md` 扩展名），返回 `text/markdown; charset=utf-8`。
- **范围**：仅包含 `page` 集合；可通过 `llms.contentRawMarkdown.excludeCollections` 排除特定集合。将 `llms.contentRawMarkdown` 设为 `false` 可完全禁用该端点。
- **输出**：如果请求的文档缺少顶级标题或描述，路由会在返回前把标题和描述补到 Markdown 正文前面。
- **llms.txt 链接**：`llms.txt` 中生成的文档链接会自动改写为 `/raw/...md` 端点（除非该集合被排除或该功能被禁用），这样智能体抓取的就是精简的 Markdown 而非完整 HTML，既能减少 token 消耗，也能提升响应速度。可通过 `llms.contentRawMarkdown.rewriteLLMSTxt` 控制（默认为 `true`）。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/content', 'nuxt-llms'],
  llms: {
    contentRawMarkdown: {
      // Optional: prevent specific page collections from being exposed
      excludeCollections: ['blog'],
      // Optional: keep llms.txt links pointing to rendered pages
      rewriteLLMSTxt: false,
    },
  },
})
```

## 章节

生成内容时，你可以创建自定义章节，把内容处理成对 LLM 友好的格式。

你可以向 `llms.sections` 数组添加自定义章节，并为每个章节定义 `contentCollection` 和 `contentFilters` 选项。

::prose-warning
如果 `contentCollection` 选项中未定义任何集合，模块只会把 [page](https://content.nuxt.com/docs/collections/types#page-type) 集合添加到 LLMs 模块。
::

### `contentCollection`

该选项用于指定使用哪个内容集合作为来源。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  llms: {
    sections: [
      {
        title: 'Documentation',
        description: 'Technical documentation and guides',
        contentCollection: 'docs',
       },
    ],
  },
})
```

### `contentFilters`

该选项定义用于在集合中筛选特定内容的过滤器。

你可以精确控制哪些内容会被包含。每个过滤器由以下部分组成：

- `field`：要检查的内容属性
- `operator`：比较运算符（`=`、`<>`、`>`、`<`、`LIKE`、`IN`、`NOT IN`、`IS NULL`、`IS NOT NULL` 等）
- `value`：用于比较的值

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  llms: {
    sections: [
      {
        title: 'Documentation',
        description: 'Technical documentation and guides',
        contentCollection: 'docs',
        contentFilters: [
            // Only include markdown files
            { field: 'extension', operator: '=', value: 'md' },
            // Only include published content
            { field: 'draft', operator: '<>', value: true },
            // Filter by directory
            { field: 'path', operator: 'LIKE', value: '/guide%' },
        ]
      },
    ],
  },
})
```
