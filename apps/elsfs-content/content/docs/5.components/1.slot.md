---
title: 插槽
description: 把 Markdown 注入 Vue 组件的最快方式。
---

当你用 MDC 语法在组件内部编写内容和段落时，可以使用 Vue 的 `<slot>` 组件来渲染这些内容。

## 用法

如果你不想修改渲染后的内容，直接使用 Vue 的 `<slot>` 组件即可。

```vue [components/content/Callout.vue]
<template>
  <div class="callout">
    <slot />
  </div>
</template>
```

现在在 Markdown 中使用它：

```mdc [content/index.md]
::callout
This is a callout.
::
```

渲染出的 HTML 将是：

```html
<div class="callout">
  <p>This is a callout.</p>
</div>
```

这种用法与使用原生 `<slot>` 组件类似。

### 去除包裹

`mdc-unwrap` prop 允许你从渲染后的内容中移除一个或多个包裹元素。当你想提取嵌套在原生 Markdown 语法中的内容时，这很有用。指定的每个标签都会从 AST 中移除。

让我们去掉上一个示例中的 `<p>` 元素：

```vue [components/content/Callout.vue]
<template>
  <div class="callout">
    <slot mdc-unwrap="p" />
  </div>
</template>
```

现在渲染出的 HTML 将变为：

```html
<div class="callout">
  This is a callout.
</div>
```

### 具名插槽

`name` prop 允许你按名称绑定插槽。当你想渲染的不是默认插槽时，这很有用。

我们来改进 `Callout` 组件，为它添加一个 `title` 插槽：

```vue [components/content/Callout.vue]
<template>
  <div class="callout">
    <h2 v-if="$slots.title">
      <slot name="title" mdc-unwrap="p" />
    </h2>
    <slot />
  </div>
</template>
```

现在在 Markdown 中使用它：

```mdc [content/index.md]
::callout
#title
Please be careful!
#default
Using MDC & Vue components is addictive.
::
```

渲染结果将是：

```html
<div class="callout">
  <h2>Please be careful!</h2>
  <p>Using MDC & Vue components is addictive.</p>
</div>
```

当不使用 `title` 插槽时，`h2` 元素不会被渲染。

## Props

- `mdc-unwrap`：是否去除包裹的内容。当你想提取嵌套在原生 Markdown 语法中的内容时，这很有用。指定的每个标签都会从 AST 中移除。
  - **类型：** `boolean` 或 `string`
  - **默认值：** `false`
  - **示例：** `'p'` 或 `'ul li'`
