Prose 组件是 HTML 排版标签的替代品。Prose 组件提供了一种自定义内容 UI 的简单方式。

要覆盖某个 Prose 组件，请在项目的 `components/content/` 目录中创建一个同名组件（例如 `components/content/ProseA.vue`）。

::note
Prose 组件最初来自 [`@nuxtjs/mdc`](https://github.com/nuxt-modules/mdc)。
::

## `ProsePre`

::code-group
````md [Code]
  ```js [file.js]{2} meta-info=val
  export default () => {
    console.log('Code block')
  }
  ```
````

  :::code-preview{icon="i-lucide-eye" label="预览"}
  ```js [file.js]
  export default () => {
    console.log('Code block')
  }
  ```
  :::
::

组件属性将为：

```json
{
  code: "export default () => {\n    console.log('Code block')\n}"
  language: "js"
  filename: "file.js"
  highlights: [2]
  meta: "meta-info=val"
}
```

想进一步了解语法高亮，请查看[高亮选项](/docs/getting-started/configuration#highlight)。

::callout{type="warning"}
如果你想在文件名中使用 `]`，需要用 2 个反斜杠进行转义：`\\]`。这是必要的，因为 JS 会自动转义字符串中的反斜杠，于是 `\]` 会被解析为 `]`，从而破坏我们的正则匹配。
::
