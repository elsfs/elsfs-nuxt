欢迎使用 Nuxt Content v3。这是一次重大升级，为你的 Nuxt 项目带来了更强的性能和一系列创新功能。作为这款基于 Git 的 CMS 的最新版本，它针对现代应用开发做了全面优化。

## 新特性

### 内容集合

集合（Collection）用于在项目中组织相关内容，帮助你更高效地管理大规模数据。主要优势包括：

- **结构化数据**：在 [`content.config.ts`](/docs/collections/define#defining-collections) 中配置数据库架构并定义集合
- **类型安全的查询**：所有工具函数都直接集成 TypeScript
- **自动校验**：确保 frontmatter 字段与数据文件（json、yml……）之间的数据一致性
- **高级查询构造器**：轻松对集合进行筛选、排序和分页
- **Studio 集成**：通过 [Studio](https://nuxt.studio) 获得增强的表单生成和最佳编辑体验

详细了解[内容集合](/docs/collections/define)。

### 性能提升

v2 面临的一大挑战是存储文件所需的打包体积过大，这对无服务器部署的影响尤为明显。

v3 通过在生产环境中改用基于 SQL 的存储解决了这一问题。这一切换无需任何配置，可支持开发模式、静态生成、服务端托管、无服务器以及边缘部署。

::prose-note
新的数据库系统改进了数据文件的存储与组织方式，带来更好的性能和可扩展性。此次更新完全在底层完成，不会影响你在 Content 中可使用的文件类型（`yml`、`json` 和 `markdown` ）。
::

主要优势包括：

- **优化的查询**：SQL 存储实现极速的数据检索
- **广泛的兼容性**：我们基于适配器的系统可在所有部署模式下接入 SQL 数据库（[服务端](/docs/deploy/server)、[无服务器](/docs/deploy/serverless) 和 [静态](/docs/deploy/static)）。我们也欢迎社区贡献更多适配器。

### TypeScript 集成

新的集合系统会为你的所有数据自动生成 TypeScript 类型。每个工具函数和 API 都会依据你的集合定义获得强类型，从而在整个开发过程中提供可靠的类型安全。

### Nuxt Studio 集成 :badge[即将推出]{color="neutral"}

[Nuxt Studio](https://nuxt.studio) 与 v3 的设计初衷就是完美互补。[studio 模块](https://github.com/nuxt-content/nuxt-studio)正在打造一个理想的环境：开发者专注于代码，团队成员则通过直观的界面管理内容。
