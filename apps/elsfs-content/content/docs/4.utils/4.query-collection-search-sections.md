## 用法

使用自动导入的 `queryCollectionSearchSections` 从特定集合中生成可搜索的分段。这在为应用创建高级搜索功能或内容发现特性时特别有用。

```vue [app.vue]
<script>
const { data: sections } = await useAsyncData('search-sections', () => {
  return queryCollectionSearchSections('docs')
})
</script>
```

::tip
`queryCollectionSearchSections` 工具函数在 Vue 和 Nitro 中均可使用。有关在服务端使用的更多细节，请参阅[服务端用法](#server-usage)。
::

## API

### `queryCollectionSearchSections(collection: CollectionName, options?: SearchSectionsOptions)`

从指定集合生成可搜索的分段。

- 参数：
  - `collection`：在 `content.config.ts` 中定义的集合的键。
  - `options`：（可选）包含以下属性的对象：
    - `ignoredTags`：生成分段时要忽略的标签名数组。默认为空数组。
    - `minHeading`：用于切分的最小标题层级（例如 `'h2'`）。默认为 `'h1'`。
    - `maxHeading`：用于切分的最大标题层级（例如 `'h3'`）。默认为 `'h6'`。
    - `extraFields`：要从集合条目中额外包含到分段对象里的字段数组。
- 返回值：一个 Promise，解析为可搜索分段的数组。每个分段是一个包含以下属性的对象：
  - `id`：分段的唯一标识符。
  - `title`：分段的标题（通常是标题文本）。
  - `titles`：父级分段标题的数组，表示层级关系。
  - `content`：分段的文本内容。
  - `level`：分段的标题层级（1-6），其中 1 是最高层级。

## 示例

下面的示例展示如何使用 `queryCollectionSearchSections` 从 `docs` 集合创建可搜索的分段：

```vue [pages/[...slug\\].vue]
<script>
const { data: surround } = await useAsyncData('foo-surround', () => {
  return queryCollectionSearchSections('docs', {
    ignoredTags: ['code'],
    minHeading: 'h2',
    maxHeading: 'h3',
    extraFields: ['author', 'date'],
  })
})
</script>
```

## 服务端用法

Nuxt Content 提供了类似的工具函数，用于在服务端查询集合。唯一的区别是，你需要把 `event` 作为 `queryCollectionSearchSections` 函数的第一个参数传入。

```ts [server/api/search-sections.ts]
export default eventHandler(async (event) => {
  const sections = await queryCollectionSearchSections(event, 'docs')
  return sections
})
```

:::note
请确保创建 `server/tsconfig.json` 文件并填入以下内容，以避免类型错误。

```json
{
  "extends": "../.nuxt/tsconfig.server.json"
}
```
:::
