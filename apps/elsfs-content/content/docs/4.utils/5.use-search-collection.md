---
title: useSearchCollection
description: useSearchCollection 组合式函数提供由 SQLite FTS5 驱动的全文搜索，支持前缀匹配、BM25 排序和摘要片段。
---

## 用法

使用自动导入的 `useSearchCollection` 组合式函数在一个或多个集合中搜索。它会基于内容分段构建 FTS5 索引，并提供即时返回的排序搜索结果。

```vue [app.vue]
<script setup lang="ts">
const { status, search } = useSearchCollection('docs')

const query = ref('')
const results = ref([])

watch(query, async (value) => {
  results.value = value ? await search(value) : []
})
</script>
```

::note
`useSearchCollection` 仅在客户端运行。FTS5 索引在浏览器中使用 SQLite WASM 构建。
::

## 类型

```ts
function useSearchCollection<T extends keyof PageCollections>(
  collection: MaybeRefOrGetter<T | T[]>,
  opts?: GenerateSearchSectionsOptions & { immediate?: boolean }
): {
  status: Ref<'idle' | 'loading' | 'ready' | 'error'>
  search: (query: string, opts?: SearchCollectionOptions) => Promise<SearchResult[]>
  init: () => Promise<DatabaseAdapter>
}
```

## API

### 参数

- `collection`：单个集合键、集合键数组，或响应式 ref/getter。当值发生变化时，会针对新的集合重建 FTS 索引。
- `opts`：（可选）索引构建选项：
  - `immediate`：是否立即开始构建索引。默认为 `true`。设为 `false` 可推迟到首次调用 `search()` 或显式调用 `init()` 时再进行。
  - `ignoredTags`：提取分段内容时要忽略的标签（例如 `['code']`）。
  - `minHeading`：用于切分分段的最小标题层级（例如 `'h2'`）。默认为 `'h1'`。
  - `maxHeading`：用于切分分段的最大标题层级（例如 `'h4'`）。默认为 `'h6'`。

### 返回值

- `status`：表示索引状态的响应式 ref：`'idle'`、`'loading'`、`'ready'` 或 `'error'`。
- `search(query, opts?)`：执行搜索查询。返回一个包含排序结果的 promise。
  - `query`：搜索字符串。自动支持前缀匹配（输入 `compo` 即可匹配到 "composable"）。
  - `opts`：（可选）搜索选项：
    - `limit`：最大结果数。默认为 `20`。
    - `fields`：将搜索限制在特定列（`'title'` 或 `'content'`）。
    - `minTermLength`：跳过短于此值的词项。默认为 `1`。
    - `weights`：控制排序行为。
      - `title`：标题匹配的提升因子。默认为 `20`。
      - `content`：内容匹配的提升因子。默认为 `5`。
      - `heading`：控制标题层级提升的指数（`0.5` = 平方根曲线，`1` = 线性，`0` = 禁用）。默认为 `0.5`。
    - `snippet`：返回高亮文本摘录。
      - `columns`：要对哪些列生成摘要（`['title']`、`['content']` 或两者）。默认为 `['content']`。
      - `around`：匹配项周围的 token 数量。默认为 `30`。
      - `tag`：用于高亮的 HTML 标签。默认为 `'mark'`。
- `init()`：手动触发索引构建。在 `immediate: false` 时很有用。

### 结果类型

```ts
interface SearchResult {
  collection: string
  id: string
  title: string
  titles: string[]
  level: number
  content: string
  rank: number
  snippets?: { title?: string, content?: string }
}
```

## 示例

### 基本搜索

```vue [SearchPage.vue]
<script setup lang="ts">
const { status, search } = useSearchCollection('docs')

const query = ref('')
const results = ref([])

async function onSearch() {
  results.value = query.value
    ? await search(query.value, { limit: 20 })
    : []
}
</script>

<template>
  <UInput v-model="query" :disabled="status !== 'ready'" @input="onSearch" />
  <ul>
    <li v-for="result in results" :key="result.id">
      <NuxtLink :to="result.id">{{ result.title }}</NuxtLink>
    </li>
  </ul>
</template>
```

### 多集合搜索

```vue [GlobalSearch.vue]
<script setup lang="ts">
const { status, search } = useSearchCollection(['docs', 'blog'])

const results = ref([])
const query = ref('')

watch(query, async (value) => {
  results.value = value
    ? await search(value, {
        limit: 20,
        snippet: { columns: ['content'], around: 40 },
      })
    : []
})
</script>
```

### 延迟初始化

```vue [LazySearch.vue]
<script setup lang="ts">
const { status, search, init } = useSearchCollection('docs', {
  immediate: false,
})

async function onFocus() {
  if (status.value === 'idle') {
    await init()
  }
}
</script>
```

### 响应式集合

```vue [VersionedSearch.vue]
<script setup lang="ts">
const version = ref('v4')
const collection = computed(() => `nuxt-${version.value}`)

const { status, search } = useSearchCollection(collection)
</script>

<template>
  <select v-model="version">
    <option>v3</option>
    <option>v4</option>
    <option>v5</option>
  </select>
</template>
```

当集合值发生变化时，会丢弃 FTS 索引并针对新的集合重建。

## 与 queryCollectionSearchSections 的对比

| | `useSearchCollection` | `queryCollectionSearchSections` + Fuse.js |
|---|---|---|
| **依赖** | 无（内置 FTS5） | 需要外部库 |
| **索引** | SQLite 倒排索引 | 内存中的 JS 扫描 |
| **速度** | O(log n) 索引查找 | 每次查询 O(n) |
| **摘要片段** | 内置 | 需手动实现 |
| **拼写容错** | 仅前缀匹配 | 完整模糊匹配（编辑距离） |
| **多集合** | 原生支持 | 需手动合并 |

当你需要快速、零依赖的搜索时，请使用 `useSearchCollection`。当你需要容忍拼写错误的模糊匹配时，请将 `queryCollectionSearchSections` 与 Fuse.js 或 MiniSearch 搭配使用。
