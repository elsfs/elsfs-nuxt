## 单文件数据源

当你把一个集合指向单个 CSV 文件（而不是 glob 模式）时，Nuxt Content 会**把每一行数据视为集合中独立的一项**。

- **定义集合**：把 `source` 设置为单个 `.csv` 文件的路径。
- **生成条目**：每一行数据都会成为一个条目，行内的字段位于顶层（没有 `body` 数组）。
- **ID**：条目 ID 会带上 `#<rowNumber>` 后缀，其中 `#1` 表示表头之后的第一行数据。

```ts [content.config.ts]
import { defineCollection, defineContentConfig } from '@nuxt/content'
import { z } from 'zod'

export default defineContentConfig({
  collections: {
    people: defineCollection({
      type: 'data',
      source: 'org/people.csv',
      schema: z.object({
        name: z.string(),
        email: z.string().email()
      })
    })
  }
})
```

```csv [content/org/people.csv]
name,email
Alice,alice@example.com
Bob,bob@example.com
```

每一行都会生成各自的条目。例如，第一行数据的 ID 以 `#1` 结尾，第二行以 `#2` 结尾。你可以按任意列进行查询：

```ts
const { data: alice } = await useAsyncData('alice', () =>
  queryCollection('people')
    .where('email', '=', 'alice@example.com')
    .first()
)

const { data: allPeople } = await useAsyncData('all-people', () =>
  queryCollection('people')
    .order('name', 'ASC')
    .all()
)
```

::note
- 表头行是必需的，并且不会被转成条目。
- 使用单文件数据源时，条目在顶层包含各行的字段（没有 `body`）。
- 如果你更希望把每个 CSV 文件当作一个条目、所有行都放在 `body` 中，请使用 `org/**.csv` 这样的 glob 数据源，而不是单个文件。
::

## 多文件数据源

如果你在配置中把 `*/**.csv` 用作 `source`，Nuxt Content 对它们的处理方式会与单文件集合不同。  
**每个文件（而不是每行）都会被当作一个条目**，各行会被解析为条目对象的 `body` 字段，形式为数组。

```ts [content.config.ts]
import { defineCollection, defineContentConfig } from '@nuxt/content'
import { z } from 'zod'

export default defineContentConfig({
  collections: {
    charts: defineCollection({
      type: 'data',
      source: 'charts/**.csv',
      schema: z.object({
        // Body is important in CSV files, without body field you cannot access to data array
        body: z.array(z.object({
          label: z.string(),
          value: z.number()
        }))
      })
    })
  }
})

```

在 `content/charts/` 目录中创建图表文件。

::code-group
```csv [content/charts/chart1.csv]
label,value
A,100
B,200
C,300
```

```csv [content/charts/chart2.csv]
label,value
Foo,123
Bar,456
Baz,789
```
::

::warning
每个 CSV 文件都应有一个定义列名的表头行，解析时会把这些列名用作对象的键。
::

现在我们可以查询图表：

```vue
<script lang="ts" setup>
// Find a single chart
const { data: chart1 } = await useAsyncData('chart1', () => {
  return queryCollection('charts')
    .where('id', '=', 'charts/charts/chart1.csv')
    .first()
})

// Get all charts
const { data: charts } = await useAsyncData('charts', () => {
  return queryCollection('charts')
    .order('id', 'ASC')
    .all()
})

</script>

<template>
  <ul>
    <li v-for="chart in charts" :key="chart.id">
      <!-- CSV data are in `chart.body` as an array -->
      <p v-for="data in chart.body">
        {{ data.label }} - {{ data.value }}
      </p>
    </li>
  </ul>
</template>
```

## 配置

你可以在 `nuxt.config.ts` 中配置 CSV 文件的解析方式：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  content: {
    build: {
      csv: {
        // Convert CSV data to JSON objects
        json: true,
        // Specify custom delimiter (default is ',')
        delimiter: ','
      }
    }
  }
})
```

配置中设为 `json: true` 后，每一行都会被转换为一个 JavaScript 对象，并以表头行作为键：

```json
[
  {
    "id": "1",
    "name": "John Doe",
    "email": "john@example.com"
  },
  {
    "id": "2",
    "name": "Jane Smith",
    "email": "jane@example.com"
  }
]
```

## 自定义分隔符

如果你的 CSV 文件使用了不同的分隔符，可以在配置中指定它：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  content: {
    build: {
      csv: {
        delimiter: ';' // Use semicolon as delimiter
      }
    }
  }
})
```

这样就能解析如下形式的 CSV 文件：

```csv [semicolon-data.csv]
id;name;email
1;John Doe;john@example.com
2;Jane Smith;jane@example.com
```

::note
如果你不需要 CSV 支持，可以在配置中设置 `csv: false` 来禁用 CSV 解析器。
::
