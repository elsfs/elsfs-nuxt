## 用法

### 定义集合

```ts [content.config.ts]
import { defineCollection, defineContentConfig } from '@nuxt/content'
import { z } from 'zod'

export default defineContentConfig({
  collections: {
    blog: defineCollection({
      type: 'page',
      source: 'blog/*.md',
      schema: z.object({
        date: z.string()
      })
    })
  }
})
```

::note{to="/docs/collections/types#page-type"}
进一步了解 `page` 集合类型。
::

### 创建 `.md` 文件

在 `content/blog/` 目录中创建博客文章。

::code-group
```md [foo.md]
---
date: 2020-11-11
---

# Foo

This is Foo blog post.
```

```md [bar.md]
---
date: 2024-12-12
---
Hello
I am bar. Nice to meet you.
```
::

### 查询 Markdown 文件

现在我们可以查询博客文章了：

```ts
// Get the foo post
const fooPost = await queryCollection('blog').path('/blog/foo').first()

// Find all posts
const allPosts = await queryCollection('blog').order('date', 'DESC').all()
```

### 显示 Markdown

要显示 Markdown 文件的内容，你可以使用 [`<ContentRenderer>`](/docs/components/content-renderer) 组件。

```vue [blog/[slug\\].vue]
<script setup>
const slug = useRoute().params.slug
const { data: post } = await useAsyncData(`blog-${slug}`, () => {
  return queryCollection('blog').path(`/blog/${slug}`).first()
})
</script>

<template>
  <!-- Render the blog post as Prose & Vue components -->
  <ContentRenderer :value="post" />
</template>
```

::note
进一步了解 [`<ContentRenderer>`](/docs/components/content-renderer) 组件和 [`Prose Components`](/docs/components/prose)。
::

## Frontmatter

Frontmatter 是基于 Markdown 的 CMS 的一种约定，用于为页面提供元数据，例如 description 或 title。在 Nuxt Content 中，frontmatter 使用 YAML 语法，以 `key: value` 键值对的形式书写。

这些数据在渲染内容时可用，并且可以存储你需要的任何信息。

### 语法

你可以在 `content/` 目录下 Markdown 文件的顶部，用 `---` 标识符声明一个 frontmatter 块。

```md [content/index.md]
---
title: 'Title of the page'
description: 'meta description of the page'
---

<!-- Content of the page -->
```

```ts [example.ts]
const home = await queryCollection('content').path('/').first()

console.log(home.title)
// => 'Title of the page'
console.log(home.description)
// => 'meta description of the page'
console.log(home.body)
// => AST object of the page content
```

### 原生参数

|               |           |                          |                                                                                                                        |
| ------------- | --------- | ------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| 键            | 类型      | 默认值                   | 描述                                                                                                                   |
| `title`       | `string`  | 页面的第一个 `<h1>`      | 页面标题，也会被注入到 meta 中                                                                                         |
| `description` | `string`  | 页面的第一个 `<p>`       | 页面描述，会显示在标题下方并被注入到 meta 中                                                                           |
| `navigation`  | `boolean` | `true`                   | 定义该页面是否包含在 [`queryCollectionNavigation`](/docs/utils/query-collection-navigation) 的返回值中。              |

::warning
你在 frontmatter 块中定义的其他参数需要在 schema 中声明（参见本页顶部示例中的 date 参数），才能用它们进行查询。
::

### Vue 组件

你可以在 Markdown 文件中使用任何 Vue 组件。

我们提供了一种特殊语法，让你在 Markdown 文件中使用组件更加方便。

```mdc [content/index.md]
::component-name
Default slot content
::
```

::warning
如果你不使用 `components/content/` 目录，那么在 Markdown 中使用的组件必须在 Nuxt 应用中标记为 `global`。请访问 [Nuxt 3 文档](https://nuxt.com/docs/guide/directory-structure/components) 了解更多。
::

#### 块级组件

块级组件是指可以接收 Markdown 内容或另一个组件作为插槽的组件。

该组件必须至少包含一个 `<slot />` 组件，用于接收格式化文本。

在 Markdown 文件中，使用 `::` 标识符来使用该组件。

::code-group
```mdc [index.md]
::card
The content of the card
::
```

```html [Card.vue]
<!-- components/content/Card.vue -->
<template>
  <div class="p-2 border bg-white dark:bg-black dark:border-gray-700 rounded">
    <slot />
  </div>
</template>
```

  :::code-preview{icon="i-lucide-eye" label="预览"}
    ::::example-card
    The content of the card
    ::::
  :::
::

#### 插槽

组件的插槽可以接收内容或另一个组件。

- **默认插槽**渲染块级组件内部的顶层内容，也可以使用 `#default`
- **具名插槽**使用 `#` 标识符来渲染对应的内容。

::code-group
```mdc [index.md]
::hero
My Page Title

#description
This will be rendered inside the `description` slot.
::
```

```html [Hero.vue]
<template>
  <section>
    <h1 class="text-4xl">
      <slot mdc-unwrap="p" />
    </h1>
    <slot name="description" />
  </section>
</template>
```

  :::code-preview{icon="i-lucide-eye" label="预览"}
    ::::example-hero
    My Page Title

    #description
    This will be rendered inside the `description` slot.
    ::::
  :::
::

::note
进一步了解 [`<slot />`](/docs/components/slot) 组件。
::

::tip
你可以在组件的插槽中使用 Markdown：

  :::code-group
  ```mdc [index.md]
  ::my-title
  A [rich text](/) will be **rendered** by the component.
  ::
  ```
  
  ```html [MyTitle.vue]
  <template>
    <h1 class="text-4xl">
      <slot mdc-unwrap="p" />
    </h1>
  </template>
  ```

    ::::code-preview{icon="i-lucide-eye" label="预览"}
      :::::example-title
      A [rich text](/) will be **rendered** by the component.
      :::::
    ::::
  :::
::

#### Props

使用 MDC 向组件传递 props 有两种方式。

##### **内联方式**

`{}` 标识符通过 `key=value` 语法以简洁的方式向组件传递 props。

::code-group
```mdc [index.md]
::alert{type="warning"}
The **alert** component.
::
```

```vue [Alert.vue]
<script setup>
const props = defineProps({ type: { type: String } })

const alertClass = computed(() => {
  return {
    warning: 'bg-orange-100 border-orange-200 dark:bg-orange-900 dark:border-orange-800',
    info: 'bg-blue-100 border-blue-200 dark:bg-blue-900 dark:border-blue-800',
    success: 'bg-green-100 border-green-200 dark:bg-green-900 dark:border-green-800',
  }[props.type]
})
</script>

<template>
  <div
    class="text-black p-2 border dark:text-white rounded"
    :class="alertClass"
  >
    <slot mdc-unwrap="p" />
  </div>
</template>
```

  :::code-preview{icon="i-lucide-eye" label="预览"}
    ::::example-alert{type="warning"}
    The **alert** component.
    ::::
  :::
::

多个 props 之间可以用空格分隔：

```mdc
::alert{type="warning" icon="exclamation-circle"}
Oops! An error occurred
::
```

`v-bind` 简写 `:` 也可以用来把 prop 绑定到 frontmatter 中的某个值。

```mdc
---
type: "warning"
---

::alert{:type="type"}
Your warning
::
```

如果你想向组件传递数组或对象作为 props，可以把它们以 JSON 字符串的形式传入，并在 prop 键前加一个冒号来自动解码该 JSON 字符串。注意这种情况下值字符串要使用单引号，这样才能在内部使用双引号来传入合法的 JSON 字符串：

::code-group
```mdc [array.md]
::dropdown{:items='["Nuxt", "Vue", "React"]'}
::
```

```mdc [number-array.md]
::dropdown{:items='[1,2,3.5]'}
::
```

```mdc [object.md]
::chart{:options='{"responsive": true, "scales": {"y": {"beginAtZero": true}}}'}
::
```
::

##### **YAML 方式**

YAML 方式使用 `---` 标识符，每行声明一个 prop，这样有助于提高可读性。

::code-group
```mdc [index.md]
::icon-card
---
icon: IconNuxt
description: Harness the full power of Nuxt and the Nuxt ecosystem.
title: Nuxt Architecture.
---
::
```

```html [IconCard.vue]
<script setup>
defineProps({
  title: {
    type: String,
    default: 'Default title'
  },
  description: {
    type: String,
    default: 'Default description'
  },
  icon: {
    type: String,
    default: 'IconMarkdown'
  }
})
</script>

<template>
  <div class="p-6 border bg-white dark:bg-black dark:border-gray-700 rounded">
    <component :is="icon" class="w-20 h-20" />
    <h2 class="text-3xl font-semibold mb-2">
      {{ title }}
    </h2>
    <p>{{ description }}</p>
  </div>
</template>
```

  :::code-preview{icon="i-lucide-eye" label="预览"}
    ::::example-icon-card
    ---
    description: Harness the full power of Nuxt and the Nuxt ecosystem.
    icon: i-simple-icons-nuxtdotjs
    title: Nuxt Architecture.
    ---
    ::::
  :::
::

### 属性

属性用于高亮和修改段落的一部分。其语法与行内组件和 Markdown 链接的语法非常相似。

可用的值包括所有具名属性、使用 `.class-name` 记法的 class，以及使用 `#id-name` 的 ID。

::code-group
```mdc [index.md]
Hello [World]{style="color: green;" .custom-class #custom-id}!
```

  :::code-preview{icon="i-lucide-eye" label="预览"}
  Hello [World]{#custom-id .custom-class style="color: green;"} !
  :::
::

除了 MDC 组件和 `span` 之外，属性语法还适用于图片、链接、行内 `code`、\**加粗*\* 和 \_斜体\_ 文本。

::code-group
```md [index.md]
Attributes work on:

- [Attributes](#attributes){style="background-color: green;"}, `code`{style="color: cyan;"},
- _italic_{style="background-color: yellow; color:black;"} and **bold**{style="background-color: lightgreen;"} texts.
```

  :::code-preview{prose label="预览"}
  Attributes work on:

  - [Attributes](#attributes){style="background-color: green;"}, `code`,
  - *italic* and **bold** texts.
  :::
::

### 绑定数据

你可以使用 `{{ $doc.variable || 'defaultValue' }}` 语法在 Markdown 文档中绑定数据。这些值可以在文档顶部的 YAML frontmatter 中定义，也可以在每个 MDC 组件内部定义，或者通过 `<ContentRenderer>` 组件的 `data` prop 注入。

#### 在 YAML 中定义

```mdc
---
title: 'Title of the page'
description: 'meta description of the page'
customVariable: 'Custom Value'
---

# The Title is {{ $doc.title }} and customVariable is {{ $doc.customVariable || 'defaultValue' }}

```

#### 通过 `<ContentRenderer>` 在外部定义

```html [test.vue]
<template>
  <div>
    <ContentRenderer :value="data" :data="mdcVars"/>
    <button type="button" v-on:click="mdcVars.name = 'Hugo'">Change name</button>
  </div>
</template>

<script setup lang="ts">
const { data } = await useAsyncData(() => queryCollection('content').path('/test').first());
const mdcVars = ref({ name: 'Maxime'});
</script>
```

```mdc [test.md]
# Hello {{ $doc.name || 'World' }}

```

## Prose 组件

在 Nuxt Content 中，prose 指的是由 Markdown 语法生成的 HTML 标签，例如标题层级和链接。

每个 HTML 标签都对应一个 Vue 组件，因此你可以在需要时覆盖它们，例如 `<p>` 会变成 `<ProseP>`。

如果你想自定义某个 Prose 组件，推荐步骤如下：

- 查看原始的[组件源码](https://github.com/nuxt-modules/mdc/blob/main/src/runtime/components/prose)。
- 使用完全相同的 props。
- 在你的 `components/content/` 目录中，给它起相同的名字。
- 把它变成你自己的 🚀。

::note{to="/docs/components/prose"}
在 Prose Components 章节中阅读完整的 Prose 参考文档。
::

## 代码高亮

Nuxt Content 使用 [Shiki](https://github.com/shikijs/shiki)，它通过 VSCode 主题为 token 着色。

代码高亮同时适用于 [`ProsePre`](/docs/components/prose#prosepre) 和 [`ProseCode`](/docs/components/prose#prosecodeinline)。

代码块的每一行都会在 `line` 属性中获得自己的行号，因此可以给行加标签或单独设置样式。

## 图片

你可以把图片添加到 `public` 目录中：

```bash [Directory structure]
content/
  index.md
public/
  image.png
nuxt.config.ts
package.json
```

然后像下面这样在 `content` 目录的 Markdown 文件中使用它们：

```md [content/index.md]
![my image](/image.png)
```

## 摘要

可以使用 `<!--more-->` 作为分隔符，从内容中提取内容摘要或概要。

```md [content/index.md]
---
title: Introduction
---

Learn how to use `@nuxt/content`.

<!--more-->

Full amount of content beyond the more divider.
```

除非在 frontmatter 的 props 中另行定义，否则 description 属性会包含摘要内容。

如果文本中没有 `<!--more-->` 分隔符，那么摘要就是 undefined。

::tip
如果你想使用摘要功能，就应该在集合的 schema 中定义 `excerpt` 字段。

```ts [content.config.ts]
const content = defineCollection({
  type: 'page',
  source: '**',
  schema: z.object({
    excerpt: z.object({
      type: z.string(),
      children: z.any(),
    }),
  }),
})
```

进一步了解[集合 schema](/docs/collections/define#collection-schema)。
::

示例变量会被注入到文档中：

```json
{
  "excerpt": Object
  "body": Object
  // ... other keys
}
```
