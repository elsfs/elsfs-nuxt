快速开始

- 准备 SQLite 连接器
  - 方案 A（推荐在 Node.js 22+ 上使用）：使用原生 `node:sqlite`
  - 方案 B（传统方式）：在你的项目中安装 `sqlite3` 包。
- 前往 AWS Amplify 控制台，使用你的 Git 仓库创建一个新项目并部署应用。
::

:hr

Nuxt Content 项目可以零配置部署到 AWS Amplify。
该模块会自动检测 AWS Amplify 环境，并为部署准备好所需的配置。

## 方案 A：使用原生 `node:sqlite`

要使用原生 `node:sqlite` 包，你需要把 Node 版本改为 22+。这可以在 Amplify 控制台中通过 `Build Settings` > `Live Package Updates` > `Package (Node.js version) = 22` 轻松完成。

也可以通过 `preBuild` 阶段中的 `amplify.yml` 实现。

```yml
frontend:
  phases:
    preBuild:
      commands:
        - nvm install 22
        - nvm use 22
        - node -v
        - npm ci
```

::warning
如果你对内容使用 SSR，Nitro 会默认将 Amplify 运行时设为 Node 20。由于 `node:sqlite` 需要 Node 22+，你需要在 `nuxt.config.ts` 中显式设置运行时版本：

```ts
nitro: {
  awsAmplify: {
    runtime: 'nodejs22.x',
  },
},
```
::

## 方案 B：使用 `sqlite3`

你只需在项目中安装 `sqlite3` 包，然后前往 AWS Amplify 控制台，使用 Git 仓库创建一个新项目。

搞定 :tada:

::note
默认情况下，模块会使用位于 `/tmp` 目录的 SQLite 数据库。你可以提供自己的数据库配置来覆盖默认配置。
::
