---
title: Vercel
description: 将你的 Content 应用部署到 Vercel
---

::card
快速开始

- 执行 `npx vercel deploy` 命令，或前往 Vercel 控制台，使用 Git 仓库创建一个新项目。
::

:hr

Nuxt Content 项目可以零配置部署到 Vercel。该模块会自动检测 Vercel 环境，并为部署准备好所需的配置。

你只需执行 `npx vercel deploy` 命令，或前往 Vercel 控制台使用 Git 仓库创建一个新项目。

就这样 :tada:

::note
默认情况下，模块会使用 Vercel 上位于 `/tmp` 目录的 SQLite 数据库。你可以提供自己的数据库配置来覆盖默认配置。
:br
Vercel 支持多个数据库服务商，你只需在 `nuxt.config.ts` 中提供正确的连接字符串，即可使用其中任意一个。
::

请查看：

- [Nuxt 部署文档](https://nuxt.com/deploy/vercel)
- [Vercel 文档](https://vercel.com/docs/deployments/deployment-methods)
