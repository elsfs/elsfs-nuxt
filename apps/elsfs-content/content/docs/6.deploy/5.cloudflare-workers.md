---
title: Cloudflare Workers
description: 将你的 Content 应用部署到 Cloudflare Workers
---

::card
快速开始

1. 使用 `cloudflare_module` 预设，并将兼容日期设置为 `2024-09-19` 或更晚。
2. 在 Cloudflare 控制台中创建 D1 数据库，并以 `DB` 绑定名将其连接到你的项目，同时在 `nuxt.config.ts` 文件中配置数据库。
3. 构建并部署你的应用
::

:hr

Nuxt Content 模块内置了与 [Cloudflare Workers](https://workers.cloudflare.com) 的集成，用于部署你的内容。

该模块会自动检测构建目标，并为 Cloudflare Workers 准备好所需的配置。

你只需创建一个 Cloudflare D1 数据库并将其连接到你的项目。创建 D1 数据库后，你应当在
`nuxt.config.ts` 文件中通过 `nitro.cloudflare.wrangler.d1_databases` 选项定义数据库配置。

默认情况下，模块会使用 `DB` 绑定名。你可以通过在 `nuxt.config.ts` 中提供自己的数据库配置来覆盖它。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  compatibilityDate: "2025-05-15",
  nitro: {
    preset: 'cloudflare_module',
    cloudflare: {
      deployConfig: true,
      wrangler: {
        d1_databases: [
          {
            binding: 'DB',
            database_name: 'database-name',
            database_id: '*********-***-****-****-*********'
          }
        ]
      },
    },
  }
})
```

::note
如果你想使用其他绑定名，可以在 `nuxt.config.ts` 中提供自己的数据库配置来覆盖。请查看[数据库配置](/docs/getting-started/configuration#d1)
::

::note
要把 Nuxt 项目部署到 Cloudflare Workers，你需要使用 `2024-09-19` 或更晚的兼容日期。
::

使用 `nuxi build` 命令构建你的项目，然后用 `wrangler deploy` 命令部署项目。

```bash
npx wrangler deploy
```
