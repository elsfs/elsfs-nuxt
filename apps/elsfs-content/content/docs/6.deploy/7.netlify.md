---
title: Netlify
description: 将你的 Content 应用部署到 Netlify
---

::card
快速开始

- 前往 Netlify 控制台，使用 Git 仓库创建一个新项目。
- 在 `Dependency management` 下的 `Site Configuration` 中，把 Node 版本改为 `20.x` 或更高。
- 前往 `deploys` 并重试上一次部署。
::

:hr

Nuxt Content 项目可以零配置部署到 Netlify。该模块会自动检测 Netlify 环境，并为 Netlify 准备好所需的配置。

你只需前往 Netlify 控制台，使用 Git 仓库创建一个新项目。

::note
默认情况下，Netlify 使用模块不支持的 Node.js 18.x。你需要在 `Dependency management` 下的 `Site Configuration` 中修改 Node.js 版本。
::

就这样 :tada:
