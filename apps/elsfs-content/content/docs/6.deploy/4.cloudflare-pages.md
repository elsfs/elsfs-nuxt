快速开始

1. 使用 `nuxi build --preset=cloudflare_pages` 构建你的应用
2. 在 Cloudflare 控制台中创建 D1 数据库，并使用绑定名 `DB` 将其连接到你的项目
3. 部署/重新部署你的应用
::

:hr

Nuxt Content 模块内置了与 [Cloudflare Pages](https://pages.cloudflare.com) 的集成，用于部署你的内容。

该模块会自动检测构建目标，并为 Cloudflare Pages 准备好所需的配置。

你可以在 `nuxi build` 命令中使用 `--preset=cloudflare_pages` 选项，也可以通过 `nuxt.config.ts` 配置预设。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  nitro: {
    preset: 'cloudflare_pages',
  },
});
```

## D1 数据库

Nuxt Content 模块要正常工作，**必须**为应用连接一个 D1 数据库。默认情况下，模块使用绑定名 **`DB`**。你可以通过在 `nuxt.config.ts` 中提供自己的配置来覆盖[数据库配置](/docs/getting-started/configuration#d1)。

创建新的 Cloudflare Pages 项目后，你需要创建一个新的 D1 数据库并将其连接到该项目。请确保使用与模块相同的绑定名。

### 本地预览

`nuxi dev` 和 `nuxi build` 不需要任何额外配置，但在本地用 `nuxi preview` 测试构建产物时，需要配置 Cloudflare 的 Wrangler，以便提供一个临时的本地数据库供 Nuxt Content 绑定。这可以通过 `wrangler.jsonc` 或 `wrangler.toml` 文件完成。由于 Wrangler 创建的是本地数据库，`database_name` 和 `database_id` 可以（但不必）与生产环境中的值一致。

```jsonc [wrangler.jsonc]
{
  "d1_databases": [
    {
      "binding": "DB",
      "database_name": "example-db",
      "database_id": "example-db-id"
    }
  ]
}
```
