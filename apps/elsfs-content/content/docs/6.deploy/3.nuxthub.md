---
title: NuxtHub
description: 将你的 Content 应用部署到 NuxtHub
---

Nuxt Content 模块内置了与 [NuxtHub](https://hub.nuxt.com) 的集成，用于部署你的内容。

要启用 NuxtHub 集成，你需要安装 `@nuxthub/core` 模块并在 `nuxt.config.ts` 中注册它。更高效的方式是使用 `nuxi module` 命令一次性完成这两件事。

```bash [Terminal]
npx nuxi module add hub
```

就这么简单 🎉

::callout
Nuxt Content 模块会自动读取 NuxtHub 的数据库选项，从而共用同一个数据库来存储 Nuxt Content 数据。
::

更多信息请查看 [NuxtHub 文档](https://hub.nuxt.com)。
