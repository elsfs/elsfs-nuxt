## 什么是 Node.js 预设？

Node 预设是 Nuxt 的默认预设。构建项目时，Nuxt 会输出一个 Node.js 服务器，你可以用 `node .output/server/index.mjs` 运行它。

## 环境要求

如果你使用默认的 `better-sqlite3` 模块来操作 SQLite 数据库，
那么必须部署到 Glibc 版本高于 2.29 的操作系统上，例如 Debian 11、Ubuntu 20.04。

::note
你可以用 `ldd --version` 查看 Glibc 版本。更多细节请查看 [issue #3248](https://github.com/nuxt/content/issues/3248)。
::

## 使用 Node.js 预设构建

使用 Nuxt build 命令构建项目：

```bash [Terminal]
nuxi build
```

使用 Node 服务器预设运行 `nuxi build` 时，产物是一个入口文件，用于启动一个可直接运行的 Node 服务器。

```bash [Terminal]
$ node .output/server/index.mjs
Listening on http://localhost:3000
```

::note
启动服务器时，SQLite 数据库会在服务端加载；在浏览器中进行客户端导航或操作时，也会在浏览器端加载。
::
