## 什么是静态托管？

静态托管是一种把网站构建为静态文件（HTML、CSS、JS）并提供服务的托管方式，这些文件可以由任意静态文件服务器提供。

Nuxt Content 可以借助 Nuxt 的预渲染能力部署到静态托管服务。

## 使用 SSG 构建

要通过静态站点生成构建应用，请运行以下命令：

```bash
npx nuxi generate
```

::tip{icon="i-lucide-check"}
该命令会生成一个包含静态站点的 `dist/` 目录。你可以把它上传到任意静态托管服务。
::

Nuxt 会通过内部爬虫自动预渲染所有页面，你可以用 `nitro.prerender` 选项自定义它的行为。

::note{to="https://nuxt.com/docs/getting-started/prerendering"}
在 Nuxt 中进一步了解预渲染。
::

## 数据库怎么办？

Nuxt Content 会在浏览器中使用 [WASM SQLite](/docs/advanced/database#wasm-sqlite-in-browser) 加载数据库，这样在客户端导航或操作时发生的内容查询就会在浏览器中运行。
