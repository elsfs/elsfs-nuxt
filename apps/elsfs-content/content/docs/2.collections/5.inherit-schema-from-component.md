你可以把 Vue 组件的 props 复用为集合模式的一部分。这有助于让内容模型与 UI 保持一致、减少重复，并防止两者脱节。

## 工作原理

Nuxt Content 提供了 `property()` 辅助函数，它会在你的校验器之上增加以下工具方法：

- **inherit(path)**：用从 `path` 处 Vue 组件推断出的 props JSON Schema 替换当前对象模式

底层实现上，Nuxt Content 会通过 `nuxt-component-meta` 读取组件的 props，将其转换为 JSON Schema，然后合并进你的集合模式。

## 示例

```ts [content.config.ts]
import { defineContentConfig, defineCollection, property } from '@nuxt/content'
import { z } from 'zod'

export default defineContentConfig({
  collections: {
    pages: defineCollection({
      type: 'page',
      source: '**/*.md',
      schema: z.object({
        // Reuse props from a local component
        hero: property(z.object({})).inherit('app/components/HeroSection.vue'),

        // Reuse props from a dependency (path is resolved like an import)
        button: property(z.object({})).inherit('@nuxt/ui/components/Button.vue')
      })
    })
  }
})
```

## 注意事项

- `inherit()` 的参数会像模块路径一样解析。你可以传入相对于项目根目录的路径，或一个包路径。
- `inherit()` 需要用在对象字段上（例如 `property(z.object({}))`）。
- 支持嵌套使用：你可以把继承得到的对象放在其他对象和数组中；Nuxt Content 会递归替换 `$content.inherit` 标记。
- 如果组件无法解析，模式会回退到原来的对象定义。

::tip
如果你需要在组件 props 之上自定义输入，可以把 `inherit()` 与 `editor(...)` 搭配使用，以获得更好的 Studio 表单。
::
