一款轻量的 Nuxt 主题，用于构建由 Markdown 驱动的网站，基于 Nuxt Content、TailwindCSS 和 Iconify

- 在 Markdown 页面中使用布局
- 享受自动生成的 meta 标签
- 可配置的 prose 组件
- 根据页面自动生成导航
- 在亮色与暗色模式之间切换
- 访问来自 100 多个图标集的 10 万个图标
- 使用 Shiki 高亮代码块

#right
  :::template-features
  ---
  features:
    - label: Nuxt 架构
      content: 充分发挥 Nuxt 3 及其模块生态的全部能力。
    - label: 支持 Nuxt Studio

        外观。
    - label: Vue 组件
      content: 在内容中插入内置组件（或你自己的组件）。
    - label: 编写 Markdown
      content: 享受 Markdown 的简洁易用，并探索 MDC 语法。
    - label: 随处部署
      content: 在 Studio 中一键部署，或在 Vercel、Netlify 上零配置部署。
        可在静态生成、按需渲染（Node）或 CloudFlare workers 边缘
        渲染之间任选。
    - label: 可扩展
